# 🗽 NYC Taxi Demand Prediction System (AI Dispatcher)

**BigQuery ML × Tableau を用いた、ドメイン知識に基づくリアルタイム配車最適化システム**

---

## 📋 プロジェクト概要

ニューヨーク（NYC）の数千万件に及ぶタクシー乗車実績データ、地理データ、および外部の気象データを BigQuery 上で統合・解析し、「ベテラン配車担当者（ディスパッチャー）の勘と経験」をデータサイエンスで再現したシステムです。

単なる時系列予測にとどまらず、現場のオペレーションに即応できるよう、1時間ごとのエリア別需要を予測し、Tableau で「未来の需要予測ヒートマップ」として可視化しました。

## 🧠 ドメイン知識をフル活用した特徴量エンジニアリング

現場のディスパッチャーの思考プロセスを SQL（Window関数）でロジック化し、以下の4つの多角的アプローチから特徴量を設計しました。

| カテゴリ | 特徴量名 | 現場目線（ドメイン知識）の意図 |
|----------|----------|----------|
| 時系列・カレンダー | `hour_of_day`, `day_of_week`, `is_weekend` | 平日の通勤ラッシュと、週末の夜遊び需要の周期性を捉える |
| 潮目の変化（ラグ） | `lag_1h`, `lag_24h`, `lag_168h` | 直前の動き、前日の同じ時間、先週の同じ曜日のベースライン |
| 需要の勢い（トレンド） | `moving_avg_3h`, `demand_velocity` | 直近3時間の移動平均に加え、「1時間前と2時間前の差分（加速度）」を算出し、需要が急上昇しているか・落ち着き始めているかを学習 |
| エリアの特性（空間） | `is_manhattan`, `is_airport` | ビジネス街（ミッドタウン）と、フライト到着時に需要が急増する空港（JFK/LGA）の特殊性を分離 |
| 人間の心理（外部要因） | `mean_temperature`, `is_rainy_day` | 「雨が降ったら地下鉄や徒歩を避けてタクシーに乗る」という行動心理を特徴量化 |

## 📈 機械学習モデルの構築と精度評価

大規模データを Python 環境へ転送するコストを排除するため、データベース内で並列学習が完結する BigQuery ML（勾配ブースティングツリー）を採用しました。

数百万件の学習データを用いて、未知期間（2022年2月1日）の需要予測を実施しました。

### モデル評価指標

#### MAE（平均絶対誤差）
**8.93台**

- エリア別・時間帯別の激しい需要変動の中で、予測誤差を平均約9台以内に抑制

#### R² Score（決定係数）
**0.943（94.3%）**

- 現実世界の複雑なタクシー需要の変動のうち、94.3%をモデルのみで説明・予測可能
- 実運用レベルで高い信頼性を持つ予測性能を達成

## 📊 ビジネス価値の可視化（Tableau）

AIが算出した予測結果を、現場担当者が秒単位で意思決定に利用できるダッシュボードとして実装しました。
**[Tableau Public で実際のインタラクティブ・ダッシュボードを見る](https://public.tableau.com/views/NYCTaxiDemandPredictionSystem/1_1?:language=ja-JP&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)**

### ① 予実推移ラインチャート

- 実績値（青）と予測値（オレンジ）を重ねて表示
- ラッシュ時間帯や深夜帯の需要変動に対しても高い追従性を確認
- モデルの精度を視覚的に検証

### ② 実務用需要予測ヒートマップ

- NYC Taxi Zone の GIS データと結合
    - 各エリアの形状データを紐付け、空間的な需要の偏りを直感的に把握可能
- 未来時刻の需要分布を地図上に可視化
    - 予測モデルのアウトプットをリアルタイムな配車戦略に直結させるビジュアル設計
- 平日の夕方（17〜18時）や夜間（22〜23時）のピーク時の需要集中を確認
    - 退勤・空港ラッシュや歓楽街への急激な需要の波をAIが正確に捉え、マンハッタン中心部や JFK 空港周辺が濃く染まる様子を可視化
- 配車優先エリアの判断を支援
    - 経験の浅いドライバーでも「次にどこへ向かうべきか」が1秒で判断できる仕組みを実装

## 🎯 本プロジェクトで得られた知見

- SQLのみで高度な特徴量エンジニアリングを実装可能
- BigQuery ML を活用することで大規模データを高速学習
- ドメイン知識を反映した特徴量設計が予測精度向上に大きく寄与
- GISデータとBIツールを組み合わせることで、予測結果を意思決定可能な情報へ変換できることを実証
